Also included: `Procfile` (Heroku), `render.yaml` (Render), `vercel.json` (Vercel), `railway.json` (Railway) and a `Dockerfile` (Koyeb, Fly.io, VPS, etc.).

**Optional env vars:** `PORT`, `CHANNELS_URL` (json list of channels to auto-follow, default is the Adevos-X url2.json).

> Note: Vercel is serverless, so long pairing sessions can be cut off. For reliable pairing prefer Render, Heroku, Railway, Koyeb or a VPS.
